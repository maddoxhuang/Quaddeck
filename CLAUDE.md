# Claude Code repository entry point

Before changing this repository, read `docs/AI-WORKFLOW.md` completely and
follow it as the shared source of truth for both Claude Code and Codex.

Start every task by reading what Codex may have left behind: the open threads
in `docs/handoffs/BOARD.md`, the notes beside it, and the `Agent:` trailers
of recent commits. Section 1 of the workflow gives the exact commands.

The project must remain a native Windows C++20 application built with the
existing MSVC, CMake and vcpkg environment. Do not replace the technology
stack or bypass the repository's verification command.
